# 散场之后

个人作品集与独立匿名论坛，使用原生 HTML、CSS、JavaScript、Node.js 内置 SQLite。无第三方服务端依赖。

## 运行网站

需要 Node.js 24 或更高版本。现在已有数据库与后台，不能通过双击 HTML 使用全部功能。在本目录运行：

```sh
npm run init-admin
npm start
```

首次初始化命令在本机终端设置管理员密码，输入不会回显。也可以运行 `node init-admin.mjs --generate` 自动生成随机密码。已存在管理员时，此命令不会覆盖账号。

默认访问地址为 `http://127.0.0.1:4173`，仅限本机；端口被占用时可通过 `PORT` 设置其他端口。Windows 也可使用同目录的 `Start-Local.ps1` 隐藏启动服务。

独立页面：

- `/works`：作品集。初始没有作品，不包含虚构示例。
- `/forum`：自由论坛。访客可以直接发帖、回复，昵称选填，无需账号。
- `/about`：关于我。
- `/admin`：已有管理员登录，前台没有入口。直接访问 `/admin.html` 不提供页面。

没有用户系统、注册页、注册接口或在线创建管理员功能。管理员只有一个，在服务器本机初始化；隐藏后台入口不能替代密码验证，所有后台接口仍需验证登录。

## 管理功能

- 作品：上传封面、视频、图片、PDF；素材排序和说明；存草稿、发布、下架、删除、首页精选。
- 论坛：隐藏与恢复帖子、置顶、关闭与开放回复、删除帖子、隐藏与删除回复。
- 站点：名称、署名、首页文字、个人介绍、联系邮箱、作品分类。
- 安全：密码加盐 scrypt、HttpOnly 会话、CSRF 校验、跨站写入限制、登录和匿名发言限流、文件签名检查、非公开素材权限检查。
- 发言默认即时公开；同一来源发帖间隔至少 20 秒、每小时最多 15 条，回复间隔至少 10 秒、每小时最多 40 条。限流是防刷措施，不是账号登录要求。
- 匿名仅表示无账号：服务端会短期保存 IP 的 HMAC 摘要用于限流，事件保留最多 24 小时；不承诺无法追踪的匿名。
- 桌面和手机响应式布局、深浅主题、键盘访问和弹窗关闭。

## 后续作品

直接在聊天中提交作品文件、名称、分工和介绍，我可以接着整理并添加；资料格式见 `WORK_SUBMISSION.md`。也可以自己在 `/admin` 里维护作品。

`site.json` 仅是首次启动时的站点默认值；启动后以数据库设置为准。站名“散场之后”和署名“小影”可在后台修改。头像仍为你提供的原图；首屏影院照片仅是视觉背景，不是你的作品。

## 数据与备份

作品、帖子、回复、管理员密码哈希及站点设置保存到 `data/portfolio.sqlite`。素材在 `uploads/`。重启不会丢失数据；主题偏好在浏览器内。

备份时先停止服务，再整体备份 `data/` 与 `uploads/`，恢复时一起还原。不要把数据库、上传目录或私人管理资料提交到公开仓库。删除作品记录不会物理删除上传素材，以免误删复用素材；必要时停机后核对再清理。

## 上线说明

这是本地可运行版本，不是已经发布的公网网站。公网部署需要 Node.js 主机、持久化磁盘、HTTPS 和正确的 `APP_ORIGIN`，例如 `https://example.com`。服务器默认只绑定 `127.0.0.1`，反向代理可转发到该地址；确有需要时可配置 `HOST`。

只有在可信反向代理覆盖 `X-Forwarded-For`，且应用不能被绕过代理直接访问时，才配置 `TRUST_PROXY=1`。上传大小、请求超时和持久化目录也应在代理端同步设置。开放论坛上线前应配置监控、备份、内容规则、隐私说明；基础限流不能完全阻止垃圾信息。

运行测试：`npm test`。服务端支持视频 Range 请求；浏览器可用 Node 内置测试之外的 Playwright 工具验证。
